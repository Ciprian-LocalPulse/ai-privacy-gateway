# Security Policy

## Supported Versions

We actively maintain and patch security vulnerabilities in the following versions:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

As an enterprise privacy proxy, **security is our highest priority**. If you discover a security vulnerability or data leak within the gateway architecture, please **DO NOT** open a public GitHub issue. 

Instead, report the vulnerability privately by emailing the repository owner directly.

### What to Include:
* A detailed description of the vulnerability.
* Steps to reproduce or a minimal Proof of Concept (PoC) script.
* Potential impact (e.g., identity leaks, upstream key exploitation, streaming buffer overrides).

We will acknowledge your report within 48 hours and provide a timeline for a coordinated disclosure and patch release.
